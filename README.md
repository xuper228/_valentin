# Photo Valentin

Повноекранне безрамкове слайд-шоу для Windows на Electron.

## Запуск

1. Додайте фото у папку `photos` (`jpg`, `jpeg`, `png`, `webp` або `gif`).
2. Встановіть Node.js 20+.
3. У цій папці виконайте:

```powershell
npm install
npm start
```

Вікно одразу відкриється на весь екран без рамок. Фотографії змінюються кожні 4,2 секунди, а нове фото прилітає з випадкового боку. Для завершення закрийте процес `Photo Valentin` через Диспетчер задач.

## EXE-файл

Щоб зібрати переносний `.exe`:

```powershell
npm run build
```

Готовий файл з'явиться у папці `dist`.
